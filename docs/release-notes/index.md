# Release notes

The release notes list the changes of each release of GECKO, the MATLAB toolbox, and of geckopy, the Python package. The GECKO page lists the releases from 4.0.0b3; the notes of earlier releases are on the [GitHub releases page](https://github.com/CompMetEng/GECKO/releases). The geckopy page shows the `CHANGELOG.md` of the version that this site documents, from 4.0.0b1; the entries of the earlier 0.x releases are in the [CHANGELOG.md](https://github.com/CompMetEng/geckopy/blob/main/CHANGELOG.md) of the repository.
